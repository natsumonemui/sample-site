## Astro
[ブログ作成チュートリアル \| Docs](https://docs.astro.build/ja/tutorial/0-introduction/)
チュートリアルが分かりやすくて楽しかった
実質GitとGitHubとNetlifyのチュートリアルでもある
量も程よい（公式は3日間想定ぽい、5日で完了）ので、気になってる人はとりあえずやってみるといいかも？
[はじめに \| Docs](https://docs.astro.build/ja/getting-started/)
公式ドキュメントも充実していて、日本語ローカライズ済みのページも多い

## erudite（Astroコミュニティテーマ）
[Themes \| Astro](https://astro.build/themes/)
Astroには有志が作ったテーマ（テンプレート）が相当数あり、気に入ったテーマをGitHubからクローンして、自分好みにカスタマイズできる
ここの作業感はHTMLテンプレート弄ってるときとほぼ同じ…
[astro-erudite \| Astro](https://astro.build/themes/details/astro-erudite/)
ブログ・ミニマル・フリーで絞り込んでも結構な数で悩んだが、最終的にeruditeというテーマにした
デモサイトに掲載されている、コンセプトやアップデート解説などの記事がよかったため→[Introducing astro-erudite v2 \| astro-erudite](https://astro-erudite.vercel.app/blog/introducing-v2)
- ライト・ダークモード切替が実装済み（これはおそらく他の多くのテーマもそう）
- ネイティブCSSを使用している
  Tailwind CSSにも興味はあるが、今回の目的はあくまでサイト改装であり、Tailwind CSSまで手を広げると学習コストが高くなりすぎると判断した
- Sätteri採用
  2026/06/23の大型アップデートAstro7.0で、マークダウンをHTMLに変換するデフォルトプロセッサがSätteriになった
  以前のUnifiedとSätteriは互換性がない部分も多いので、最初からSätteri前提で作られている当テーマを採用することで、移行の手間をなくせた

## GitHub Copilot
Visual Studio Code内で使う
Astro DocのMCPサーバーがあることにサイト改装終わってから気づいた→[AIツールでAstroサイトを構築する \| Docs](https://docs.astro.build/ja/guides/build-with-ai/)
主にJavaScript・TypeScriptが必要な部分で使用
あくまで補助なので、何をどうやりたいかはある程度プロンプトで書いておかないと、素人目にも絶対違うだろみたいな変更をかましてくる
一応無料でも使えるが、モデルが（2026年6月時点）Claude Haiku 4.5固定なので、複数ファイルを参照するようなタスクはちょっと物足りないし、使用量はすぐなくなった　体力がない気分屋
せっかくなので10ドル/月のProを試した
- 1500AIクレジットが与えられる。モデルごとにトークン（文字数）あたりの消費クレジットが決められていて、性能の低いモデルに簡単なタスクをやらせるほど消費クレジットは下がり、性能の高いモデルに複雑なタスクをやらせるほど消費クレジットは上がる
- モデルauto（自分でも選べるが、autoだとクレジットが10％オフになる。大体Codex5.3）、～～を実装して。といった曖昧なプロンプトで使ったところ、一つの指示におよそ5クレジットから80クレジットを消費して、3日で1500クレジットがなくなった
- 契約日ではなく月でクレジットがリセットされるので、一ヶ月だけでいいなら月末に契約して使い切って翌月を迎えることで、制限期間を挟まずに二ヶ月分のクレジットを使える
- 6月に仕様が変わり、回数制限からトークンベースになったことで、かなりコスパが厳しくなったらしい→[GitHub Copilotの料金改定で大騒ぎになっているので、トークン削減の最新手法をまとめてみた - Qiita](https://qiita.com/shinkai_/items/626dfa7857f2d554784e)
  これのケイブマン（原始人）プロンプトが力技すぎて好き　AIに原始人っぽく喋らせて文字数を削減

## Git
無知の頃にGitHubだと思っていたもの、実はGitだったらしい
便利だが、いつもVSCodeやGitHub越しの存在なので、そことの境目が分からなくなる
やらかしても巻き戻せるという安心感が得られる
## GitHub
Gitのハブという、ネーミング通りのコミュ強サービス
本当に色々やっていただいているので、足を向けて寝られない
ちょっとした変更ならスマホブラウザでできるのが地味に偉い
## GitHub Actions
ブログリポジトリとサイトリポジトリの同期をやっていただいている
## Cloudflare Pages/Workers
ビルド→distの中身をサーバーにアップロードする　という手作業の代わりに、GitHubリポジトリの変更を検知して自動でビルド&デプロイしていただいているため、頭が上がらない
2026年1月、CloudflareがAstroの開発元を買収したので、そこの相性が悪くなることはないだろうという安心感もある
類似サービスと比較して、無料枠がありえないほど寛大
## Cloudflare Registrar
独自ドメインが安くて助かる
前述の無料枠といい何か裏があるんじゃないか？とすら思ったが、単にCloudflareのビジネスモデルがすごかった
