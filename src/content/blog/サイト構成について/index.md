## 各ページ
### HOME
- ラッキーアイテム欄が欲しかったので作った　現在は全64種
  ちなみに視界に入る・聞くだけでOKという~~ガバガバ~~ルール
- リンクバナーいっぱい貼れて満足！今度同盟作ってみたい
### INFO
- 内容はほとんど改装前と変わっていない
### BLOG
- フィルターで絞り込める
- ブログ記事の見出しジャンプ機能は、テーマ（erudite）に元々ついているもの
- Obsidianから更新できる
### NOVEL
- フィルターで絞り込める
- おそらくマークダウンの仕様で、最初の全角字下げが反映されない
  次の段落以降は反映される。&amp;nbsp;の後に全角スペースを入れると反映されるので、とりあえずそれで凌ぐ
  あまり小説は更新しないので、ここは妥協してもいい
### RECORD
- 映画、本、ゲームの記録を一括で管理したかった
  国・年の絞り込み機能がめちゃくちゃ助かる（自画自賛）国コード入れたら思ったより多くなったけど
- book/film/game/otherの各ファイルでRecordEntry配列を管理して、ページ側で結合
  一応スマホのブラウザ（GitHub）からも追加できる
- 映画はFilmarks、本はビブリアで確認したため、そのアプリを使い始めた以前の記録がない
  Twitterで自ツイ検索しようとしたら検索が死んでて、ますますローカルファースト願望が強まった
- 読んだ本全部を公開するのはなんか恥ずかしいので、一部のみ…
- ゲームを記録できるアプリって意外となくて、ずっと欲しいなと思っていたので作れてよかった
  ObsidianのBasesでも作れたけど、デザインの自由度が高くて楽しい
### TEGALOG
- 背景色と文字などをサイトに合わせた
- スキン自作しようとしたけど、ゼロから作ると普通に数ヶ月かかりそうだったので断念
- いつもありがとう‼️

## 作ったけど削除したもの・作ろうとしたけど挫折したもの
- カラーテーマ
  赤、青、黄、緑のテーマ作ったけど、管理コスト増えるしライトダークだけで充分だなと思った。カラーテーマの名前を考えるのが楽しかった
- 全角字下げプラグイン
  GitHub Copilot（の中のCodex）に作らせたが、動作が不安定だった。おそらくテーマ同梱のマークダウンパーサーが Satteriで、ネット上にマニュアルがあまりないため
- Spotifyで最後に再生した曲をAPIで取得、HOMEに表示する
  開発環境だと正常に表示されていたが、Astroは静的サイトジェネレーターなので、APIの取得結果もビルド時しか更新されないことに途中で気付いた
  クライアントサイドでなんやかんややれば行けるらしいが明らかにこちらの知識レベルが足りていないのでやめた。API触れて面白かったのでヨシ！
- Cloudflare Registrarで取得したドメインのサブドメインを別レンタルサーバーで管理する
  Cloudflare Pages/WorkersでCGIは実行できないため、てがろぐを設置する場合は別のCGI可サーバーを持つ必要がある。
  どうせならURLを揃えたいと思い、独自ドメインのサブドメインだけレンタルサーバーに向けられないかと考えたが、ロリポップでは謎のエラーが出て、リトルサーバーで試そうとしたところで面倒になり大人しく提供ドメインを使うことにした　可能らしいです
